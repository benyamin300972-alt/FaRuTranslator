# نقشه راه

این نقشه راه پیشنهادی است؛ شروع هر مرحله جدید منوط به تأیید مالک پروژه است.

## مرحله صفر — تثبیت REV05 در مخزن

- [ ] انتقال سورس معتبر REV05 به GitHub
- [ ] بررسی کامل فایل‌ها و ساختار پروژه
- [ ] بررسی وابستگی‌ها و فایل‌های مدل
- [ ] ثبت نسخه‌ها و checksum فایل‌های حجیم خارج از Git در صورت نیاز
- [ ] بررسی امنیت و حذف هرگونه Secret
- [ ] Build اولیه بدون تغییر منطق برنامه
- [ ] ثبت خط مبنا و گزارش فنی

## مرحله یک — آزمون و پایدارسازی زنجیره صوتی

- [ ] بررسی ضبط صدا و مدیریت مجوزها
- [ ] بررسی کیفیت و پایداری ASR
- [ ] بررسی ترجمه و مدیریت خطا
- [ ] بررسی TTS و پخش خودکار
- [ ] بررسی توقف، لغو و شروع مجدد عملیات
- [ ] آزمون دستگاه واقعی و شرایط کمبود حافظه

## مراحل بعدی

پس از بررسی سورس REV05 و تأیید مالک، مراحل بعدی بر اساس وضعیت واقعی کد تعریف می‌شوند. قابلیت جدید یا تغییر معماری از پیش فرض نمی‌شود.
